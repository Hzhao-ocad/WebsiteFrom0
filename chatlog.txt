## To go live — 3 steps

**1. Create a Sanity project**
```bash
# In the studio/ folder:
cd studio
npm install
npx sanity init --env
# Follow prompts → creates project at sanity.io/manage
```
This writes your project ID into a `.env.local` file in `studio/`.

**2. Fill in `.env`** (root of the project)
```
SANITY_PROJECT_ID=abc123xyz    ← from sanity.io/manage
SANITY_DATASET=production
```
Also add these as environment variables in your Vercel project settings.

**3. Enter your works in Sanity Studio**
```bash
cd studio && npm run dev   # opens Studio at localhost:3333
```
Add each work with images uploaded directly to Sanity (no more `/public/images/` manual management). Then re-deploy and the Astro build will pull all data from Sanity.

The old `.md` files in `src/content/works/` can be deleted once all works are entered in Sanity.
